- **官方 Terraform/Nomad 部署路径已在 `2026.30` 退役**：`iac/` 目录、`self-host.md`、`DEV.md` 一并删除，官方预告新部署路径但尚未落地。自管 Nomad 部署需以 `2026.28` 及更早 tag 的 `iac/modules/` 资产为参考。

## 3. 配置与运行时变化

### 3.1 API 配置（`packages/api/internal/cfg/model.go`）

新增：

- `ADMIN_AUTH_PROVIDER_CONFIG`：管理端点专用 JWT/OIDC provider 配置。
- `ANALYTICS_COLLECTOR_TLS`（默认 `true`）：分析收集器 TLS；仅回环明文收集器才应关闭。
- `K8S_API_ENDPOINT`：为空用 Pod ServiceAccount（仅集群内），设置后可从集群外经 Google ADC 访问。
- `REDIS_TLS_ENABLED`、`REDIS_PASSWORD`（API/Orchestrator/Client Proxy/Dashboard API 四个服务统一新增）。
- `SECRETS_STORE_BACKEND_GRPC_ADDRESS`：secrets store 管理后端；为空时 secret 管理路由返回 403。
- `DEFAULT_PERSISTENT_VOLUME_TYPE_BY_REGION`：按区域默认卷类型，区域由节点 `region=` 标签推导。
- `PLACEHOLDER_PERSISTENT_VOLUME_TYPE`（默认 `__DEFAULT_VOLUME_TYPE__`）：响应中的默认类型占位符。

删除：

- `AUTH_DB_READ_REPLICA_CONNECTION_STRING`。

语义变化：

- `LOKI_URL` 从 required 改为可选：不设置时 API 无 Loki 客户端，日志读取经 `logs-read-config` Feature Flag（或 `LOGS_READ_CONFIG` env）路由 ClickHouse。
- `SERVICE_DISCOVERY_PROVIDER` 移除 `envDefault:"nomad"`：未设置与显式 `nomad` 可区分；`local` 环境自动 `local`，其余按 `nomad` 解析。

### 3.2 Orchestrator 配置

- `pkg/cfg/storage.go` 新增 **per-role 存储 URL**：`TEMPLATE_STORAGE_URL`、`BUILD_CACHE_STORAGE_URL` 为权威配置；未设置时把 `STORAGE_PROVIDER`/`*_BUCKET_NAME`/`LOCAL_*_BASE_PATH` 旧风格转换为等价 URL。`S3_USE_PATH_STYLE` 解析严格（值错误即使 URL 配置也报错）。
- 存储后端新增 `azblob://`（Azure Blob）scheme；合法 scheme 为 `gs`、`s3`、`azblob`、`file`。
- `LAUNCH_DARKLY_API_KEY` 从 cfg 移除，改由共享 Feature Flags 客户端直接 `os.Getenv`（对所有服务生效）；cfg 新增 `INSTANCE_GROUP_NAME`（指标/Flag 上下文）。
- Consul 相关变量（`USE_LOCAL_NAMESPACE_STORAGE`、`CONSUL_TOKEN`）删除；`storage_kv.go` 移除，`storage_local.go` 成为唯一 slot 存储。
- 新增 `BUILD_SANDBOX_EGRESS_DSCP`（未设置继承 `SANDBOX_EGRESS_DSCP`）。
- `ARTIFACTS_REGISTRY_PROVIDER` 新增枚举 `AZURE_ACR`。

### 3.3 Client Proxy 配置

- 新增 `ORCHESTRATOR_PROXY_PORT`（默认 `5007`）：sandbox HTTP 流量代理到 Orchestrator 的端口。
- 新增 `REDIS_TLS_ENABLED`、`REDIS_PASSWORD`。

### 3.4 Dashboard API 配置

- 新增 `ADMIN_AUTH_PROVIDER_CONFIG`、`REDIS_TLS_ENABLED`、`REDIS_PASSWORD`。
- 删除 `ORY_ISSUER_URL`（issuer 一律从 `AUTH_PROVIDER_CONFIG` 解析）与 `AUTH_DB_READ_REPLICA_CONNECTION_STRING`。

### 3.5 envd

- 新增内部 CLI 参数 `-resume-handover`（live 自升级换手后重新接管进程）。

## 5. 服务发现与部署拓扑变化

- `SERVICE_DISCOVERY_PROVIDER` 合法值新增 **`nomad+kubernetes`**：同时查询两个平台并返回去重并集，用于 Orchestrator/Template Manager 双平台并存的迁移期。
- Kubernetes discovery 新增 `K8S_API_ENDPOINT`（集群外访问）；Pod `HostIP` + 固定 `5008` 组合、`hostNetwork` 假设不变。
- **Consul KV network slot 存储移除**（`8e3fdf31b`）：slot 状态只在 Orchestrator 进程内，Orchestrator 不再依赖 Consul。
- API 新增 **节点可达性跟踪**（"track whether a node is reachable, apart from its status"）与 sandbox 移除的 incarnation 固定（"let a removal pin the sandbox incarnation it meant to remove"）。
- API 新增 **rig 管理透传**：`/clusters/{clusterID}/rigs/...` 管理集群的 Orchestrator 节点池（rigs），委托给集群 edge 服务 `/v1/rigs/...`；API 不持有云凭据。本地集群无 edge 部署时对所有 rig 操作返回 501。
- 本地 sandbox 路由简化：本地节点路由改用 Redis（`2026.29`，`#3253`）。
- **Nomad IaC 退役**见第 2 节；代码层 Nomad discovery 与 node pool 调度完整保留。

## 6. 用户可见能力变化

以下能力均可由固定 `2026.30` 的 `infra/spec/openapi.yml` 与对应 handler 验证：

- **Sandbox fork**：`POST /sandboxes/{sandboxID}/fork`——原位 checkpoint 运行中的 sandbox（短暂暂停、带完整内存快照、在原节点恢复，ID 与过期时间不变），并按 count 创建副本。
- **项目 secrets 管理**：`GET/POST /secrets`、`/secrets/{secretID}`（`customer-secrets` Flag 门控；响应不携带 secret 值）。
- **envd live 升级**：resume 时把运行中 sandbox 的 envd 换成新二进制（同 PID `syscall.Exec`，stdio/PTY/进程表/退出码/文件系统 watcher 经 tmpfs 换手 blob 保留）；由 `envd-upgrade-target` Flag 控制，另有 filesystem-only 快照的离线升级 `envd-offline-upgrade-target`。
- **无 LaunchDarkly 的日志读取切换**：`LOKI_URL` 可选 + `LOGS_READ_CONFIG` 环境变量 / `logs-read-config` Flag（`8006b7863`）。
- **Dashboard 管理 API 扩容**：`/v1/management/projects/*`（项目 CRUD、成员、限额，均带单调 revision 围栏）、`/admin/clusters`、team ban/block/status/limits、admin 用户查询；数据库层默认 team 名称迁移为 project 语义（`20260723120001`）。
- UFFD 同步写保护 fault 与脏状态跟踪（`use-sync-wp`、`sync-wp-tracker-dirty`）、原位 checkpoint（`in-place-checkpoint`、`defer-memory-export`）等运行时能力以 Feature Flag 暴露，默认关闭。
- **网络 transform 通配符 domain key**（`d843e3f00`）：API 接受并持久化前导通配符 key（如 `*.example.com`），spec 文档化了精确优先/最长后缀语义。注意后续 fix `48d321beac` 被 `487527d09` revert——闭源 runtime applier 按精确 hostname 查找，因此通配符规则不保证在运行时生效，不应向用户承诺该行为。

卷内容读写路径明确由独立仓库 `e2b-dev/belt`（volume-content API）承担：控制面 API 签发 audience 为 `api.<domain>` 的 JWT，SDK 直连 `/volumecontent/...`。私有化需要完整卷内容读写时必须另行部署 belt。

## 8. 数据库与迁移风险

`2026.28 → 2026.30` 新增 **24 个** PostgreSQL migration（`infra/packages/db/migrations/`）：

- `20260706120000_add_teams_sso_organization_id.sql`：SSO org→team 映射。
- `20260707193000_user_identities_unique_user_issuer.sql`：`user_identities` 唯一索引。
- `20260714091414/15`：模板磁盘 entitlement、team limits 扩展。
- `20260723120001_rename_default_team_names_to_project.sql`：默认 team 名称改为 project 语义。
- `20260728163016_add_project_limits.sql` 及 `20260807120000` / `20260812150000`：project limits 与 member/limits projection ledger（单调 revision 围栏）。
- `20260823120000_drop_access_tokens.sql`：**删除 `access_tokens` 表与 `generate_access_token()` 函数**。
- `20260826075153_add_free_disk_limit_columns.sql`：免费层磁盘限额列。
- 其余为 autovacuum scale（env_builds/snapshots/envs/env_build_assignments）、状态统计、重复/无用索引清理。

升级流程要求不变且更严格：**先备份，单独执行 migration（`make -C infra/packages/db migrate` 或 goose `-table _migrations`），再滚动更新服务**。`access_tokens` 删除后，依赖 `sk_e2b_` 个人令牌的客户端必须在升级前切换到 API Key。

ClickHouse 侧：上游发布 `clickhouse-migrator 0.0.1`；`CLICKHOUSE_MIGRATOR_VERSION` 可从 E2B artifact registry 拉取预构建镜像。
