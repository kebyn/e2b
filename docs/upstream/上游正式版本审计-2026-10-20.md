## 可复现检查

以下命令用于复核 tag、主线和 annotated tag 的对象关系；命令只读取远端引用，不修改本地子模块：

```bash
git ls-remote https://github.com/e2b-dev/runtime.git \
  refs/tags/2026.30 refs/heads/main
git ls-remote https://github.com/e2b-dev/e2b.git \
  'refs/tags/e2b@2.57.0' 'refs/tags/e2b@2.57.0^{}' \
  'refs/tags/@e2b/python-sdk@2.57.0' 'refs/tags/@e2b/python-sdk@2.57.0^{}'
git ls-remote https://github.com/kubernetes-sigs/agent-sandbox.git \
  refs/tags/v1.0.7 'refs/tags/v1.0.7^{}'
git -C infra describe --tags --exact-match
```

预期的 Runtime 输出为 `2026.30 → f32ee8a2a50052f32e3632ceb451111a98dd5104`、`main → 0bb1c43fa22e5187b80890b24be14711ff7db6bc`；SDK 和 Agent Sandbox 的 annotated tag 还应结合 `^{}` 行读取 peeled source。历史同步说明中的 `e2b-dev/infra` 链接保留原始仓库名，以便追溯当时的版本记录；当前文档统一使用更名后的 `e2b-dev/runtime`。

## 版本升级规则

升级 Runtime 前必须同时移动 `infra/` gitlink、重新审计服务端源码和中文部署文档；不能仅因为 `runtime/main` 出现新分发资产，就把 `embed` API、配置或部署方式写入 `2026.30` 文档。SDK 和 Agent Sandbox 也分别按正式 tag 审计，不能用其中一个项目的主线或对照能力推断另一个项目的兼容范围。
